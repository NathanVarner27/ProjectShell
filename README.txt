ProjectShell is an accessibility-first PowerShell project manager for Windows.

Full setup, features, and security documentation: README.md
Development plan and v1 release verification: DEVELOPMENT-PLAN.md and RELEASE-CHECKLIST.md

Windows x64: extract the full ZIP, then double-click Install-ProjectShell.exe.
The executable requires Install-ProjectShell.ps1 and ProjectShell.ps1 beside it.
It does not request administrator elevation automatically.
